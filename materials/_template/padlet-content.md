## Pinned Post 3 — The Workflow (copy-paste prompts)

**🛠️ The build flow**

1. Sketch on paper (photo) or in Excalidraw
2. Open AI Studio → **Chat** mode → upload your image
3. Prompt:
   > Generate a single HTML file with inline CSS and JavaScript — no external libraries — that implements what I sketched. It should work when I open the file in a browser.
4. Save the file (Ctrl/Cmd+S the response → save as `index.html`)
5. Drag `index.html` onto https://app.netlify.com/drop → you get a live URL
6. Iterate in Chat: "make the button bigger", "add a score counter", "make it work on mobile"
7. Re-save, drag onto Netlify Drop again → updates instantly
